# Tool domains

Each subdirectory links to the original `Tools/<tool>/` directory. The links
contain no copied implementation. The public command map is in `tools.sh -h`;
feature and session tools remain available by direct path for skills and servers.

| Group | Use for |
| --- | --- |
| [code](code/) | Unity C# lookup, checks, and code graph |
| [documents](documents/) | Document review, diagrams, description cache, export |
| [project](project/) | Project setup and publication |
