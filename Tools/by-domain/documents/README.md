# Document tools

- [doc-review](doc-review/README.md): local document and diagram review.
- [mermaid-graph](mermaid-graph/README.md): class diagram editor and generator.
- [deimagify](deimagify/README.md): image/PDF description cache.
- [docs-export](docs-export/README.md): Confluence-ready Markdown export.

Call `bash Tools/tools.sh documents <method> ...`; list methods with
`bash Tools/tools.sh -h`.
